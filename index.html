THE PROJECT

A tool for
your own account.

X Manager is a personal X account-management application. Each owner runs their own private instance, connects their account with X API credentials, and manages conversations through a browser dashboard.

The current application supports account verification, collecting mentions, publishing text and images, replying to conversations, and reviewing publishing history. The owner controls when live publishing is enabled.

DATA & ACCESS

The context
behind a conversation.

The application uses account profile information and mentions or replies directed to the connected account. Relevant post text, post IDs, account identifiers, timestamps, and publishing outcomes are stored in the owner's deployment to maintain history and prevent duplicate processing.

API credentials are stored encrypted. The dashboard uses the owner's configured access controls. This public information page has no credential form, analytics scripts, or connection to the X API.

PLANNED

A place for future experiments.

A future version may detect selected keywords in incoming mentions or replies and respond with generated text or images. Generation will run in a separate service, so the account manager can operate independently. Automated replies are planned work and will need to meet X's applicable automation requirements.
